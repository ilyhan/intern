# Ну, погоди!

Браузерная версия игры «Ну, погоди!» в виде знакомой консоли «Электроника». Курицы несут яйца, которые скатываются по четырём дорожкам, а волк должен успеть подставить корзину. Задача — поймать как можно больше яиц и побить свой рекорд.

## Основные возможности

- **Ловля яиц**
  Перемещайте корзину между четырьмя позициями. За каждое пойманное яйцо начисляется одно очко.

- **Два режима игры**
  «ИГРА А» — обычная скорость, «ИГРА Б» — более быстрая. Выбрать режим можно кнопками на консоли. Каждое нажатие начинает новую игру и сбрасывает текущий счёт.

- **Пауза**
  Кнопка «ПАУЗА» останавливает игру и открывает окно с правилами. Нажмите «Понятно», чтобы продолжить.

- **Сохранение рекорда**
  Лучший результат сохраняется в localStorage и отображается в модальном окне. После обновления страницы рекорд остаётся в том же браузере.

## Управление

Играть можно красными кнопками на консоли или с клавиатуры:

| Клавиша | Положение корзины |
| ------- | ----------------- |
| W       | Слева сверху      |
| S       | Слева снизу       |
| E       | Справа сверху     |
| D       | Справа снизу      |

Клавиши работают по их расположению на клавиатуре, поэтому переключать русскую раскладку на английскую не нужно.

## Запуск проекта

Для запуска понадобятся Node.js и npm.

1. Откройте терминал в папке проекта и установите зависимости:

   ```bash
   npm ci
   ```

2. Запустите приложение:

   ```bash
   npm run dev
   ```

3. Откройте [http://localhost:8080](http://localhost:8080).

Чтобы собрать приложение, выполните:

```bash
npm run build
```

Результат сборки появится в папке `dist`. Картинки, звуки и шрифт хранятся в `public`: при размещении приложения их тоже нужно отдавать как статические файлы.

Проверить типы отдельно от сборки можно командой:

```bash
npx tsc --noEmit
```

## На что обратить внимание

- **Три жизни на игру**
  При промахе отнимается жизнь, внизу появляется разбитое яйцо, а остальные яйца убираются. Игра замирает на секунду и затем продолжается. Когда жизни заканчиваются, игра останавливается и открывается окно с правилами и рекордом.

- **Скорость режимов**
  В игре А яйца двигаются каждые 500 мс, в игре Б — каждые 300 мс. Новое яйцо появляется раз в четыре шага, в режиме Б они появляются чаще.

- **Звуки**
  Движение и ловля яиц сопровождаются короткими звуками из оригинальной игры.

- **Внешний вид**
  Корпус, экран, кнопки и расположение элементов сделаны по образцу консоли. Размеры интерфейса подстраиваются под ширину окна.
